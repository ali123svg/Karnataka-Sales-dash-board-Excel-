# Sales Analytics Dashboard

 data analysis project providing insights into sales performance, customer behavior, and business metrics.
Im really excited to share my excel dash board

# Data set used
< a href=https://github.com/ali123svg/Karnataka-Sales-dash-board/blob/main/Karnataka%20Store%20Data%20Analysis.xlsx> Dataset view </a>
## 📈 Analysis Performed

1. **Sales vs Orders** - Combined visualization
2. **Monthly Trends** - Peak sales identification
3. **Gender Analysis (2025)** - Men vs Women purchasing
4. **Order Status** - Fulfillment stage breakdown
5. **Top 10 States** - Geographical sales contribution
6. **Age-Gender Relation** - Demographic patterns
7. **Sales Channels** - Platform performance
8. **Top Categories** - Best-selling products
